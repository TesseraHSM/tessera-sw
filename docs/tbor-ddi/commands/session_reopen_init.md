# SessionReopenInit (Opcode 0x30)

**Handler:** `fw/core/lib/src/ddi/tbor/session_reopen_init.rs`
**Session:** InSession (session id carried; not subject to the default-PSK gate)

## Description

Phase 1 of the session **reopen** handshake.  A partition reset (NSSR,
live migration, or emulator `erase`) leaves every open session in
`NeedsRenegotiation`: in-session commands on it fail with
`SessionNeedsRenegotiation` (`0x087000C7`) until it is reopened.
Reopen re-keys the existing slot under the **same** `session_id`.

Reopen runs exactly the same Phase-1 crypto as
[`SessionOpenInit`](./session_open_init.md) (HPKE `auth_psk` export,
`info`, and `mac_resp`); the handlers share one implementation.  The
differences are:

- the host names the slot via `session_id` instead of `psk_id`; the
  role (and so the PSK slot) is taken from the slot itself.  The PSK
  is the one **currently** bound to that role — after a reset this is
  the compiled-in default;
- the slot must be `NeedsRenegotiation`; it becomes reopen-Pending.
  Repeating `SessionReopenInit` replaces the pending state.  A
  reopen-Pending slot is never evicted by a fresh `SessionOpenInit`;
- the partition identity key is regenerated by a reset, so the host
  must re-fetch `pk_hsm` before Phase 1.

The Pending state records that it was started by a reopen, so only
[`SessionReopenFinish`](./session_reopen_finish.md) can complete it.

## Request

| Field | Type | Description |
|---|---|---|
| `session_id` | `session_id` (inline) | Slot to reopen. |
| `session_type` | `u8` | Must match the slot's role (`1` = Authenticated for CO, `0` = PlainText for CU). |
| `suite_id` | `u8` | `0x01` (`P384HkdfSha384AesGcm256`). |
| `pk_init` | `buffer` (97 B) | Host ephemeral P-384 public key (SEC1 uncompressed). |

## Response

| Field | Type | Description |
|---|---|---|
| `pk_resp` | `buffer` (97 B) | HPKE encapsulated key. |
| `mac_resp` | `buffer` (48 B) | Phase-1 confirmation MAC, as for [`SessionOpenInit`](./session_open_init.md#phase-1-confirmation-mac-mac_resp). |

## Errors

| Error | Cause |
|---|---|
| `InvalidArg` | Slot is not `NeedsRenegotiation` (e.g. already `Active`), or malformed fields |
| `InvalidSessionType` | `session_type` does not match the slot's role |
| `UnsupportedSessionSuite` | Unknown `suite_id` |
| `SessionNotFound` | No such session |
